# Excel Sales Analytics Mini Project

## Project Overview
This project focuses on analyzing retail sales data using Microsoft Excel. The objective is to transform raw sales data into meaningful insights and create an interactive dashboard to support business decisions.

## Tools & Technologies
- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Slicers and Timeline
- What-If Analysis
- Scenario Manager
- Goal Seek

## Project Workflow
1. Combined 12 monthly sales files using Power Query.
2. Cleaned and transformed the data.
3. Merged customer, product, and employee master data.
4. Created PivotTables for sales analysis.
5. Developed an interactive sales dashboard.
6. Performed What-If Analysis and Scenario Manager analysis.
7. Identified key business insights and recommendations.

## Dashboard Features
- Total Revenue
- Total Orders
- Total Units Sold
- Average Order Value
- Top Region
- Top Product
- Revenue by Region
- Monthly Revenue Trend
- Revenue by Category
- Top 5 Products
- Salesperson Performance
- Revenue by Customer type
- Order Distribution by Revenue Bands
- Interactive Slicers and Timeline

## Key Business Insights
- Total Revenue: Approximately ₹2.27 Crore.
- East was the highest-performing region.
- Laptop was the top-selling product by revenue.
- January recorded the highest monthly revenue.
- Corporate customers contributed the highest revenue.

## What-If Analysis
Evaluated different revenue scenarios:
- Conservative: -5%
- Base Case: Current revenue
- Growth: +10%
- Aggressive: +20%

Used Goal Seek to identify the growth percentage required to achieve a revenue target of ₹3 Crore.

## Project Outcome
Developed an interactive Excel dashboard to analyze sales performance, identify trends, evaluate business scenarios, and support data-driven decision-making.
